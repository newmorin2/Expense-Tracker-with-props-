# React Expense Tracker using Props

## Overview

The React Expense Tracker is a beginner-friendly React application
that displays a list of expenses using reusable components,props,array methods and
Bootstrap cards.

Each expense displays its name, amount, category, and spending
status. Expenses of KSh 2,000 or more are classified as High,
while expenses below KSh 2,000 are classified as Low.

This project was built to practise fundamental React concepts,
including components, props, array methods, and conditional rendering.

## Features

- Display a list of expenses.
- Show the name, amount, and category of each expense.
- Classify expenses as High or Low.
- Use conditional styling to distinguish expense statuses.
- Display expenses in responsive Bootstrap cards.
- Calculate total amount of expenses using reduce().
- Filter high expenses using filter().
